## Getting started

1. **Fork this repository** to your own GitHub account (button in the top-right corner of this page)
2. **Clone your fork** to your laptop:
   ```bash
   git clone https://github.com/YOUR-USERNAME/cs5045.git
   ```
3. Open VS Code and open the `seminar_2/` folder
4. Open `challenge.ipynb` and run the first cell. You should see `Dataset loaded: 51 rows`
5. Work through Tasks 1–8
